## 🌐 Sobre a Organização

A **AmazinglyAI** é uma organização focada na pesquisa, desenvolvimento e implantação de soluções de inteligência artificial de alta utilidade. Nosso propósito é mitigar assimetrias de informação, reduzir a latência na tomada de decisões e construir softwares robustos que integram modelos de linguagem (LLMs) a fluxos de trabalho determinísticos e seguros.

---

## 🚀 Nosso Ecossistema Principal: Stock Agents

O **Stock Agents** é uma plataforma avançada de orquestração multi-agente assíncrona voltada para a análise preditiva e consolidada de ativos da B3. O sistema emula a mesa de operações de um fundo de *Hedge*, utilizando IA para sintetizar o consenso de um comitê de investimentos digital.

O ecossistema é dividido de forma modular e integrada através de dois repositórios:

### 🖥️ Stock-Agent-Front *(Private)*
*   **Tecnologias:** React 19 • Vite • TypeScript • Tailwind CSS
*   **Destaques:** Design focado em *Design Thinking*, redução drástica de carga cognitiva, psicologia das cores para feedback visual imediato e mecanismos rígidos de ofuscação de rotas no *client-side*.

### ⚙️ Stock-Agent-Back *(Private)*
*   **Tecnologias:** Python • FastAPI • CrewAI • Pydantic V2 • HTTPX
*   **Destaques:** API assíncrona de alta performance, pipeline rígido de execução sequencial com **6 agentes especialistas** e **1 líder de comitê** (Gestor de Portfólio). Conta com validação quarentenária de dados na borda da API para evitar injeções e garantir conformidade de contratos.
